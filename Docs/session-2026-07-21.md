## Import mechanics (how the assets were authored)
- **Files**: 29 sprite PNGs copied to `_Project/Sprites/{Ingredients,Chef}/` + hand-authored
  `.png.meta`; 23 `.asset` + `.asset.meta` in `Resources/Skins/`. Generated deterministically by
  `scratchpad/gen_skins.ps1` (guarantees unique GUIDs + unique sprite internalIDs — the project's
  flagged cross-wiring hazard).
- **Sizing win**: the artist exported ingredient alts on the **exact same canvas dims as the
  defaults**, so each alt reuses its slot's default PPU → guaranteed size match. Only Cheddar
  (881×570 vs 854×507) needed a computed PPU (667). Dogtors height-normalised to the default chef
  (worldH 1.929) via per-file PPU; `maxTextureSize: 4096` (heights up to 2097px).
- Buns = one purchasable: each bun skin carries top (`_sprite`) + bottom (`_secondarySprite`).

## ⚠️ The bug that cost a round: meta line endings
Unity rejected **every** hand-written `.meta` with *"Parser Failure at line 8: Expect ':'"* +
*"does not have a valid GUID… will be ignored"*. Cause: files were **LF-only with no trailing
newline** — Unity's YAML parser fails at EOF on the last line. Fix: normalise to **CRLF + one
trailing newline** (matches Unity-written metas). Added the `Nl` helper to the generator and
codified the rule in CLAUDE.md → Asset Conventions. (Also note: adding files outside the Editor
needs an Assets → Refresh / focus to import — a no-op 0.004s refresh in Editor.log = not scanned.)
