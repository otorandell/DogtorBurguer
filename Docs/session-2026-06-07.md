- **F-11 was recovered.** It had been folded into the F-16 config commit per
  the notes but never actually landed (inline `0.4f` still at

  the "check nothing got lost" pass; implemented with F-12.
- **Gem packs were 100% dead, not just invisible.** `activeInputHandler: 1`
  (New Input System only) means `OnMouseDown` never fires — so even a visible
  pack was uncollectable. F-48 routes taps through `TouchInputHandler` via a
  static `GemPack.TryTapAt` registry; the collider (only there for
  `OnMouseDown`) was removed with it. F-50's earmarked `_collider` cleanup is
  therefore already done.
- **F-21 blast radius.** Pause is currently *unwired* (no callers of
  `PauseGame`/`ResumeGame`), but making it an `_isPaused` modifier means
  `CurrentState` stays `Playing` while paused. `TouchInputHandler`'s input
  gate was updated to also check `IsPaused` so it stays correct once a pause
  button is wired. `GemPackSpawner` was left alone (Time.timeScale = 0 → no
  spawn during pause anyway).
- **F-37/F-39 are behavior-preserving** — the triple-chance math just moved to
  DifficultyManager; `REGULAR_INGREDIENTS[roll]` equals the old
  `(IngredientType)roll`.
- **F-9 was alpha-only.** The `sortingOrder = -1` already renders bubbles in
  front of every background layer and behind the chef; the issue was purely
  transparency. Left the order as-is (changing it to 0 would z-fight the
  chef). Alpha values (0.6 inactive / 0.85 active) are tunable.
- **F-50 is partial.** The "sorting-order sweep" commit did the sortingOrder
  portion (= the F-43 sweep). The gem-pack spawn geometry/anim-duration
  literals in `GemPackSpawner` and the `BTN_GEM_PACK` UI-color-on-world-sprite
  are still inline → F-50 remains open.
