## Consumable use effects — final art direction (dev-specified, replaces my first guess)
The model: **the drag ghost IS the nozzle**. Ghost art = nozzle (`GhostSprite`); on release over
a column the ghost **lingers** locked in place (`GhostLingers`, `GHOST_LINGER_DURATION`) while
the effect plays, then fades. Per type:
- **Ketchup**: nothing falls (`FallerSprite = null` → instant resolve on release). The stream
  extends linearly from the ghost's tip down the column; **clear flashes stagger top→bottom in
  step with the stream front** (`Ingredient.DestroyWithFlash(delay)`,
  `KETCHUP_CLEAR_START_DELAY/_STAGGER` ↔ `FX_STREAM_EXTEND_DURATION`; tip speed = 0.4/0.05 = 8 u/s).
- **Mustard**: the authored blob (`fx_mustard_drop` = Mustard_Effects_3, dropped into the OLD
  RawArt folder) falls from the lingering ghost; sweep resolves on impact. No extra nozzle pop.
- **Skewer**: full stick (`fx_skewer_falling` = "Palillo_Effects_2 1", 2700px → 4096 meta) falls
  tip-first (`FallerImpactLift`); after impact only the head (`fx_skewer_head`) slams down and
  lingers at the base — the went-through depth read. **Dev has further skewer changes queued —
  next session picks up here.**
- Ghost tuning: nozzle ghosts 1.4 world-h (30% down), `CONSUMABLE_GHOST_Y_OFFSET` −0.35.
- Dead code removed: pop-in nozzle path (`FX_NOZZLE_*`, `FX_MUSTARD_HOLD_DURATION`, MustardBurst).

## Grid ↔ play-mat alignment (measured, the "columns offset the mat" bug)
The mat's painted lanes never matched the column pitch (predates this session): painted pitch
= **507.7px** (uniform), lanes center **45.75px left** of the sprite center (asymmetric padding —
what the old hand-tuned 0.11 nudge was compensating). At the mat's world size the painted pitch
is **1.234 world** vs columns at 1.4 → outer columns sat ~0.22 off their lanes.
**Fix (dev chose "the mat leads")**: `CELL_WIDTH = 1.234` (derived from the mat), `GRID_ORIGIN_X
= -1.851`, `GRID_CELLS_X_NUDGE = 0.111` (measured), mat size untouched (6.33), `PLAY_AREA_WIDTH
5.55`. Buns (1.38) slightly overlap adjacent lanes — dev approved the look ("just perfect").
Along the way: tap circles retuned to `0.5 × CELL_WIDTH` (exact tiling, no cross-column overlap;
if vertical tolerance feels tight in play, switch the hit test to column-wide rects).
A +10% spacing stretch was tried and rejected (see git history) — the real issue was alignment.
