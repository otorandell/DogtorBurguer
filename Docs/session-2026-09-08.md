## Toolchain gotchas (bit us today)
- Git Bash heredocs EAT backslashes in python regexes → write scripts to the scratchpad.
- `grep -iE "error"` as a build gate INVERTS when errors exist (grep succeeds) → gate with
  `grep -ciE "error CS" | grep -q "^0$"`.
- `sed -i` strips CRLF from Unity metas (the meta-parser trap) → renormalize after.
- TMP components on INACTIVE hierarchies have null `font` until Awake → assign
  `TMP_Settings.defaultFontAsset` explicitly (bit the How-to bullets).
- The SDF asset is git-LFS; commit it after each good bake.
