## Gotchas resolved (now in CLAUDE.md → Asset Conventions)
- **Sprite internalID collision**: chef.png & chef_alt shared the same sprite fileID (chef_alt was
  copied from chef's meta with only the guid changed) → cross-wired refs (chef invisible / wrong art).
  Fixed by giving chef.png a unique internalID and repointing `chef_default` + `Game.unity`.
- **Large-source import**: chef (2387px) > `maxTextureSize` 2048 → texture downscaled below the pinned
  sprite rect → "rect out of bounds" error, which wiped the meta's sprite (`sprites: []`) → invisible.
  Fixed with `maxTextureSize: 4096`. Backgrounds (2604px) will need the same.
- **Crispy plate**: fine thin lines minified without mipmaps aliased. Fixed with mipmaps (+ uncompressed).
